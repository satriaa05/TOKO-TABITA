# Panduan Owner: Mengubah Halaman Tentang & Mencetak Invoice

## 1. Mengubah konten "Tentang Kami"

1. Login sebagai **Owner**.
2. Buka **Pengaturan Bisnis** di sidebar.
3. Gulir ke kartu **Konten Halaman Tentang Kami**.
4. Isi/ubah field berikut:

| Field | Fungsi |
|---|---|
| Teks kecil atas | Label kecil di atas judul (contoh: `Sejak 2010`) |
| Judul halaman | Judul utama halaman Tentang |
| Paragraf pembuka | Cerita singkat tentang Tabita Modiste |
| Paragraf cerita toko | Proses produksi, bahan, ukuran, dll. |
| Paragraf penutup | Layanan, area pengiriman, dll. |
| Judul daftar keunggulan | Contoh: `Mengapa Tabita Modiste?` |
| Daftar keunggulan | Satu poin per baris dengan format `Judul|Deskripsi` |

Contoh isi **Daftar keunggulan**:

```
Garment premium|Bahan pilihan dengan jahitan rapi.
Ukuran lokal|Size chart S–XL standar Indonesia.
Layanan personal|Konsultasi ukuran via WhatsApp.
```

5. Klik **Simpan Pengaturan**.
6. Buka menu **Tentang** di website publik untuk melihat hasilnya.

> Jika field dikosongkan, website otomatis memakai teks bawaan. Tidak perlu khawatir halaman kosong.

---

## 2. Mencetak invoice / struk

### Admin
- Buka **Pesanan → Daftar Pesanan**, klik ikon printer pada baris pesanan, **atau**
- Buka **Detail pesanan**, lalu klik **Cetak Invoice**.

### Owner
- Buka **Dashboard Owner**, lalu klik nomor invoice pada tabel **Penjualan Terbaru**.

Halaman invoice menampilkan:
- Identitas & kontak toko (diambil dari Pengaturan Bisnis),
- Nomor invoice, tanggal, status pembayaran,
- Data pembeli dan pengiriman,
- Rincian item, subtotal, diskon, ongkir, dan total,
- Tanda tangan Pembeli & Tabita Modiste.

Klik tombol **Cetak / Simpan PDF**, lalu pilih printer atau **Save as PDF**
pada dialog browser. Gunakan browser Chrome/Edge untuk hasil terbaik.

> Invoice hanya bisa diakses oleh **Admin** dan **Owner**. Pembeli tidak diberi akses ke halaman ini.
