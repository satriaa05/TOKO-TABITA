# Sumber Aset Logo Pembayaran

Semua logo di folder ini adalah aset vektor lokal, tidak mengambil gambar dari
server pihak ketiga saat halaman dibuka (tidak ada broken image / hotlink).

| File | Metode | Sumber |
| --- | --- | --- |
| `visa.svg` | Visa | Wikimedia Commons, *File:Visa Inc. logo (2021–present).svg* — <https://commons.wikimedia.org/wiki/File:Visa_Inc._logo_(2021%E2%80%93present).svg> (public domain, simple text logo). |
| `mastercard.svg` | Mastercard | Wikimedia Commons, *File:Mastercard 2019 logo.svg* — <https://commons.wikimedia.org/wiki/File:Mastercard_2019_logo.svg> (brandmark resmi sejak 2019). |
| `qris.svg` | QRIS | Wikimedia Commons, *File:Logo QRIS.svg* — <https://commons.wikimedia.org/wiki/File:Logo_QRIS.svg> (Bank Indonesia, public domain). |
| `bank-transfer.svg` | Transfer Bank | Aset generik buatan proyek ini (ikon bank + teks). Ganti dengan logo bank resmi setelah daftar bank toko ditetapkan. |

Catatan penggunaan:

- Logo digunakan hanya sebagai **informasi metode pembayaran**, bukan klaim
  bahwa transaksi kartu/QRIS sudah terintegrasi otomatis.
- Metode yang tampil di footer mengikuti pengaturan Owner. Secara default hanya
  `Transfer Bank` yang aktif karena itu metode yang benar-benar didukung alur
  checkout saat ini.
- Logo dapat diganti dari dashboard Owner tanpa mengubah kode (unggah PNG/JPG/WebP).
